رزق البنات — نسخة أولية تجريبية (PWA)

المحتويات:
- index.html: واجهة متجر عربية RTL ولوحة إدارة أولية.
- manifest.webmanifest و sw.js: أساس قابلية التثبيت والعمل دون اتصال بعد أول تحميل.

التجربة:
1) ارفع الملفات الثلاثة إلى استضافة HTTPS ثابتة (مثل استضافة صفحات ثابتة).
2) افتح رابط الموقع من هاتف Android عبر Chrome.
3) من قائمة المتصفح اختر: تثبيت التطبيق / Add to Home screen.
4) زر دخول الإدارة في هذه النسخة التجريبية يستخدم الرمز 1234.

مهم جدًا:
هذه نسخة واجهات وتجربة محلية وليست نظامًا تجاريًا جاهزًا. المنتجات والطلبات تُحفظ في تخزين المتصفح على الجهاز فقط.
لا يوجد حتى الآن خادم سحابي أو مزامنة بين أجهزة أو بوابة دفع أو واتساب فعلي أو شحن متصل أو نظام تقسيط محاسبي آمن أو صلاحيات موظفين حقيقية.
يجب تنفيذ backend آمن، ومصادقة وصلاحيات، ونسخ احتياطي، ومراجعة قانونية/محاسبية قبل استقبال طلبات أو بيانات حقيقية.
